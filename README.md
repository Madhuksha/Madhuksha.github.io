# Dinuka Dasanayaka — Software Engineer / Web Developer Portfolio

Responsive single-page portfolio using HTML, CSS and vanilla JavaScript.

## Before publishing
1. Open `index.html` and replace `YOUR_EMAIL@example.com` with your professional email address.
2. Review all skill and career descriptions for accuracy. Job descriptions are concise summaries; adjust them to match your official CV.
3. Upload the contents of this folder to the root of the `Madhuksha.github.io` repository. Keep `index.html` at the root.

## Publish with GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
Website: https://Madhuksha.github.io/

## Features
- Sticky translucent header and scroll progress indicator
- Scroll reveal animations, subtle floating UI and CSS 3D cube
- Pointer-based 3D tilt on skill cards
- Responsive mobile navigation
- Reduced-motion accessibility support
- Minimum 16px for regular interface/body copy; smaller sizes are reserved for decorative labels/metadata
- No paid hosting, frameworks or plugins required

Google Fonts are loaded online; fallback fonts are provided.
